## Contract dùng chung

**Types cố định cho các task.** Trong `core/kernel.py`: `Principal(principal_id, owner_id, harness_id, machine_id)`, `Scope(repo_id, checkout_id=None)`, `ObjectRef(kind, id, revision, digest)`, `Identity(store_id, writer_epoch, instance_id)`, `Call(tool, arguments, correlation_id, selected_scope)`, `CallContext(principal, identity, deadline_ns, selected_scope)`, `StoredResult(result_id, assignment_id, refs)`, `LineageRef(owner_id, repo_id, source: ObjectRef)`, `LineagedField(value, sources, unknown_source)`. ID server sinh bằng `new_id()` khi bản ghi mới; `owner_id`/`harness_id`/`machine_id` dùng định danh opaque đã chuẩn hóa từ principal. `revision` nguyên dương, `digest=sha256:<hex>`, deadline monotonic nanoseconds. `StoredResult` chỉ ID và typed refs, có thể encode tuple refs thành canonical JSON; không lưu body. `BrainError` thêm `unauthenticated`, `daemon_unavailable` và `policy_unavailable` với thông điệp allowlist; transport phân biệt JSON-RPC errors và tool errors.

`Call` và `CallContext` cùng dùng `selected_scope: Scope | None`. Schema `KernelHttpCall` bọc `{tool,arguments,correlation_id,selected_scope}`; scope là private transport context shim chèn từ profile, không nằm trong agent arguments. Mọi workspace tool, kể cả record_outcome chỉ có delivery_id, phải kiểm stored subject với scope này. Server-auth current grants và machine binding vẫn bắt buộc, direct HTTP assertion không tự thành authority. Request HMAC canonical `{tool,selected_scope,arguments}` sau injection, framing/correlation bỏ. Idempotency key-scope vẫn principal/tool/key để cùng key đổi checkout → conflict. Health scope=None; job scope global có principal ACL, job workspace có selected scope khớp.

**Wire.** `Call.arguments` là JSON object có `schema_version="2.0"`. Framing ID không tham gia digest. Identity trùng principal normalize bỏ, khác refuse. `workspace_id` nghĩa repo ID. Public MCP `PrepareTaskClientArgs` zero-or-one selector (IDs hoặc hint, không mixed), shim dùng selected profile đã có host lifecycle proof T0 và inject alias. HTTP `PrepareTaskDaemonArgs` exactly-one, không fallback CWD. `x-resolution="single-checkout-owner-profile-v1"` chưa freeze tới khi T0 R1 passed. Schema có hai defs/normalization order, tools/list client input và kernel normalized input. Hint opaque1..128 `[A-Za-z0-9._-]`, không raw path/remote. Snapshot ID optional. Theo owner chọn A cho R2, thiếu/slow snapshot có thể trả labeled Delivery nếu auth/scope/domain/total deadline cho phép; `snapshot_status` bắt buộc available/unavailable/deadline và nullable snapshot ID theo bảng. Mutation sau dùng task binding đúng scope. UTF-8 strict, reject duplicate keys/nonfinite/lone surrogate/bool-as-int, depth32/body1MiB/text64KiB/array1.024/JSON-RPC ID128. Mutation key `[A-Za-z0-9_-]{16,128}`. Token estimator `utf8-byte-v1`, budget default4.000/range1..4.000.
