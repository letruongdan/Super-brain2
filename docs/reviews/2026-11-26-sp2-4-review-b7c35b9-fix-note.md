## Finding 1 (P2) — `events_since_agent` Must Track Cumulative Committed Events Since the Last Agent Write

### 1. Invariant
Per §7.4, `events_since_agent` is the cumulative number of committed events added since the last agent handoff write up to the committed revision being read, never resetting across worker refreshes, resetting to `0` on agent patches, preserving across non-patch takeovers, ignoring duplicate/retried events, and remaining invariant under subsequent source quarantine or expiry.

### 2. Sibling Sweep
- **Cumulative persistence at commit time ([`_handoff_schema.py`](../../src/superbrain/storage/_handoff_schema.py#L43-L70)):** Added `events_since_agent INTEGER NOT NULL DEFAULT 0 CHECK (events_since_agent >= 0)` to unreleased store v8 `handoff_revision_headers` and `agent_event_order INTEGER NOT NULL DEFAULT 0` to `task_handoffs` (all column reads/writes remain strictly guarded behind `handoff_revision_headers` table existence so store v7 callers stay unaffected; v7 -> v8 backfill initializes `events_since_agent = 0`), plus `events_since_agent: int = 0` on [`HandoffRevisionHeader`](../../src/superbrain/ports/_handoff_types.py#L613-L667) (including `to_dict()` and `require_non_negative_int`).
- **Worker observed commit ([`_sessions_worker.py::apply_worker_commit_in_tx`](../../src/superbrain/storage/_sessions_worker.py#L513-L561), [`_handoff_schema.py::record_v8_revision_header_in_tx`](../../src/superbrain/storage/_handoff_schema.py#L331-L433)):** `apply_worker_commit_in_tx` collects unique `ev_order > prev_rowid` matching `session_task_events` into `batch_event_orders`, deduplicating duplicate/retried source tuples and ignoring already-summarized rows. `record_v8_revision_header_in_tx` reads the prior committed header at `(artifact_id, old_epoch, next_revision - 1)` (before advancing `current_revision_epoch` on post-restore commits) and persists `prev_count + count(order > agent_event_order)`.
- **Agent patch commit ([`handoffs.py::_apply_handoff_mutation_in_tx`](../../src/superbrain/storage/handoffs.py#L996-L1085) with `has_patch=True`, [`sessions.py::apply_agent_handoff_patch`](../../src/superbrain/storage/sessions.py#L512-L528)):** Resets `events_since_agent = 0` on the committed header and advances `task_handoffs.agent_event_order` to `COALESCE(MAX(event_order), 0)` so pre-patch unsummarized events later picked up by the worker do not increment the post-patch counter.
- **Takeover-only commit ([`handoffs.py::_apply_handoff_mutation_in_tx`](../../src/superbrain/storage/handoffs.py#L996-L1085) with `has_patch=False, takeover=True`):** Preserves `events_since_agent` from `(cur.artifact_id, cur.revision_epoch, cur.revision)` and keeps `task_handoffs.agent_event_order` unchanged (`COALESCE(NULL, agent_event_order)`). `not_stored_policy` branches write no new revision header and leave counters unchanged.
- **Content resolution & L1/L2 rendering ([`handoffs.py::resolve_observed_sources`](../../src/superbrain/storage/handoffs.py#L1124-L1265), [`handoffs.py::read_handoff_content_bundle`](../../src/superbrain/storage/handoffs.py#L1922-L1977), [`handoff_service.py::_render_artifact`](../../src/superbrain/application/handoff_service.py#L709-L725)):** `resolve_observed_sources` remains strictly a live content resolver over the immutable `observed_ref` ref set (`_check_blob_status` + `live_event_record`), while `read_handoff_content_bundle` forwards `hdr.events_since_agent` directly to both L1 and L2 (and L2 `revision_history` includes each revision's committed `events_since_agent`). Quarantine/tombstone/expiry of source events or `observed_ref` blobs still redacts/expires content at read time while preserving the committed `events_since_agent`.
